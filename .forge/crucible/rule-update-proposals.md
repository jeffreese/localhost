# Rule Update Proposals — localhost

When Crucible notices a recurring pattern across 3+ PRs, it proposes a rule addition here. The user reviews on cadence and decides whether to add the rule to `/Users/jeffreese/Code/localhost/.claude/rules/` for real.

## Format

```
## <proposed rule name>
- **Proposed:** <date>
- **Status:** open / accepted (added to rules) / rejected
- **Pattern observed in:** PR #<N1>, #<N2>, #<N3>
- **Proposed rule text:**
  > <one paragraph — what the rule would say>
- **Reasoning:** <why this rises to a rule>
```
